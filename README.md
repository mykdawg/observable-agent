# observable-agent

An AI agent that emits a typed stream of signals about its own execution — observable by external sensors, observability platforms, code analysis tools, and evaluation platforms.

See [`PRD.md`](./PRD.md) for the product plan and open questions, and [`CLAUDE.md`](./CLAUDE.md) for the project's development workflow and standards.

## Development

```sh
pnpm install
pnpm test
pnpm lint
pnpm typecheck
```
